# AESC MSU ML HW (2023-2024)
My coursework for the **Machine Learning** course at the **Special Educational and Scientific Center of Moscow State University (AESC MSU)**.

The repository contains practical assignments covering the **fundamental concepts and basic algorithms of machine learning**, including data preprocessing, linear and logistic regression, classification, SVMs, feature engineering, dimensionality reduction, reinforcement learning, and basic neural networks.

All assignments were completed during the course and received **excellent grades**.
